# P16.3.4 Charge Target & Replan State Hotfix

## 실제 실패 재현

P16.3.3은 안전하지 않은 2151번 충전소를 제외하고 2159번 안전 후보를
선택했지만, 최종 라우팅 거리로 에너지를 재계산하는 과정에서 충전 종료
배터리가 `80.0%`가 아닌 `79.82%`로 낮아졌습니다. Verification은 이를
`CHARGE_TARGET_POLICY_NOT_MET`으로 판정하고 LOCAL_REPLAN을 요청했습니다.

LOCAL_REPLAN에서는 모든 작업이 R2-03 고정 배정이라는 이유로 기존 시간표까지
동결되어 자동 CHARGE 작업을 다시 만들지 못했습니다. 동시에 이전 후보 경로의
task ID가 새 경로에 합쳐져 A/B/C와 오래된 CHARGE ID가 중복되었습니다.

## 수정 사항

1. `charge_target_battery`를 충전 종료 시점의 실제 목표값으로 취급합니다.
2. 라우팅 후 충전소 도착 배터리가 달라져도 목표 80%를 절대 낮추지 않습니다.
3. 충전 시간은 목표 배터리를 만족하도록 5초 단위로 올림 계산합니다.
4. 고정 로봇 배정과 시간표 동결을 분리합니다.
5. LOCAL_REPLAN 대상 작업은 R2-03 배정은 유지하면서 다시 스케줄링합니다.
6. 재계획 전에 경로·예약·명령·에너지 파생 상태를 명시적으로 초기화합니다.
7. 변경 로봇의 과거 후보 경로에서는 시작 위치만 재사용하고 과거 task ID는 제거합니다.
8. 자연어의 80% 충전·안전 도달 조건을 hard constraints에 기록합니다.

## 정책

- 최소 운용 배터리: 20%
- 안전 도달 여유: 0.5%
- 충전소 도착 기준: 20.5% 이상
- 다음 작업 투입 충전 목표: 80.0% 이상
- 안전 후보 선택: 안전 도달 후보 필터 → 설정 비용 최저 → 비용 없으면 최단거리
