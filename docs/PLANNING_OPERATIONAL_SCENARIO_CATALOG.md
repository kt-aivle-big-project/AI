# LARO 운영 계획 평가 시나리오 30종

이 카탈로그는 운영 계획 평가에서 사용하는 30개 시나리오의 의도와 규모를
요약한다. `로봇` 표기는 `전체/계획 후보`이며, 배터리 임계값 미만 또는 고장
로봇은 계획 후보에서 제외된다.

운영 비교의 Solver backend는 `cuopt`로 고정한다. INITIAL 시나리오는 각 1회,
RP01~RP09는 초기 계획과 재계획 각 1회, RP10은 초기 계획 1회 후 stale version을
Solver 호출 전에 거절한다. HUMAN_REVIEW 시나리오는 사람의 판단이 먼저 필요한
입력 게이트 검증이므로 cuOpt를 호출하지 않는 것이 정상이다.

평가는 운영 HTTP API에 노출하지 않는다. 로컬 CLI가 시나리오를 순서대로
materialize하고 같은 프로세스에서 Rule 1회·Agent 반복 비교를 직접 실행한다.
시나리오 정의 30개는
`planning_scenario_catalog.py`, 물리 창고 fixture는
`scenarios/fixtures/V13_mixed_inbound_outbound_multirobot` 한 곳만 사용한다.

## Human Review 5종

각 시나리오는 출고 1건과 로봇 6/6을 사용한다. 입력 게이트가 사람의 결정 요청을
만드는지 검증하며, 결정 전에는 실행 계획과 cuOpt 호출이 없어야 한다.

## 전체 검증에서 확인하는 항목

- 시나리오의 총 작업 수와 출고/입고 합계가 일치하는지
- 로봇 전체 수, 후보 수, 저배터리 수와 개별 배터리 값이 일치하는지
- 모든 필수 작업이 중복·누락 없이 계획에 포함되는지
- Solver 결과가 실제 `cuopt/success`인지
- Route와 MAPF 검증이 모두 통과하는지
- 재계획 시 완료·이미 적재된 작업을 다시 계획하지 않는지
- plan version, base plan 연결, 안전 인계 시각, 이전 계획 `SUPERSEDED` 처리가 맞는지
- Human Review 사유, prompt, 선택지가 비어 있지 않은지
